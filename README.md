# Vessel 
### Persian RAG

یک پروژه‌ی **Retrieval-Augmented Generation (RAG)** بهینه‌شده برای پردازش و بازیابی اطلاعات از متون فارسی.

هدف پروژه، ساخت یک Pipeline ساده و قابل توسعه برای تبدیل اسناد فارسی به داده‌های قابل جست‌وجوی معنایی، ذخیره‌ی آن‌ها در Vector Database و استفاده از نتایج بازیابی‌شده برای پاسخ‌گویی دقیق‌تر به پرسش‌ها است.

---

## Features

* پشتیبانی از متون فارسی
* Chunking مناسب برای زبان فارسی
* تولید Embedding با مدل‌های محلی
* ذخیره و جست‌وجوی Vector با ChromaDB
* Semantic Search بر اساس Similarity
* اجرای کاملاً Local با Ollama
* بدون نیاز به APIهای خارجی برای Embedding
* معماری ساده و قابل توسعه
* مناسب برای PDF، TXT و سایر منابع متنی
